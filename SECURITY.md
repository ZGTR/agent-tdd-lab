# Security

The bundled examples are offline fixtures. Do not expose demo approvals or database seeding as public endpoints. See docs/production.md for trust boundaries and effect guarantees.

Report suspected vulnerabilities privately to mohammadshakergtr@gmail.com with reproduction steps, affected version, and impact. Do not include credentials or customer data. This project does not promise a response-time SLA. Security fixes target the latest release; no long-term support policy is currently offered.
